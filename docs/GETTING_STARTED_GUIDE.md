## Quick Glossary

Here are the key words you'll see throughout OnBoardPro:

| Word | What It Means |
|------|---------------|
| **Candidate** | A person going through your hiring or onboarding process. |
| **Task Library** | A saved list of reusable tasks you can add to any checklist. |
| **Template** | A reusable checklist of tasks that you can apply to new candidates. |
| **Anchor Date** | A key date (like "Start Date") that other due dates are calculated from. |
| **Owner** | The person responsible for completing a task. |
| **Status** | Where a task is right now: Not started, Working on it, Blocked, or Done. |
| **Dependency** | When one task must be finished before another can begin. |

## Part 1: Create a Candidate

**What is a candidate?**  
A candidate is any person moving through your hiring or onboarding process. This could be a new hire, a faculty member, or a contractor. You create a candidate record to track all their tasks and progress in one place.

---

### Step 1: Open the Candidates page

1. Look at the left side of your screen.
2. Click **Candidates** in the menu.

*Why this matters:* This is where you'll see everyone currently in your pipeline.

[Screenshot: Left sidebar with Candidates highlighted]

---

### Step 2: Click the "New Candidate" button

1. Look in the top-right corner of the page.
2. Click the button that says **+ New Candidate**.

*Why this matters:* This opens the form where you'll enter the new person's information.

[Screenshot: Candidates page with New Candidate button circled]

---

### Step 3: Fill in the required fields

A form will appear. Some fields have a red asterisk (*) next to them—those are **required**. You must fill them in before you can save.

**Required fields:**

| Field | What to Enter |
|-------|---------------|
| Salutation | A title like Dr., Mr., Ms., or Mx. |
| First Name | The person's first name |
| Last Name | The person's last name |
| Email | Their email address |
| Candidate Type | What kind of person this is (Faculty, Staff, etc.) |
| Department | Which department they belong to |
| Letter of Intent Date | The date they signed their letter of intent |
| Template | The checklist of tasks to use (you can skip this for now) |

3. Fill in each required field.

*Why this matters:* OnBoardPro needs this basic information to create the record.

[Screenshot: Create Candidate form with required fields highlighted]

> **Tip:** If you don't know the Candidate Type, ask your HR team. Picking the wrong type may show the wrong templates.

---

### Step 4: Fill in optional fields (if you have the info)

These fields are helpful but not required:

| Field | What It's For |
|-------|---------------|
| Division | A smaller group within the department |
| Manager | The person's supervisor |
| Faculty Rank | For faculty only—their academic rank |
| Offer Letter Issued | The date you sent the offer letter |
| Offer Letter Accepted | The date they accepted the offer |
| Anticipated Start Date | When they're expected to begin work |

4. Fill in any optional fields you know.

*Why this matters:* These dates help calculate when tasks are due. If you add them now, the system can create accurate deadlines.

> **Note:** If you enter an "Offer Letter Accepted" date, the system will automatically generate the task list. Leave it blank if you want to add tasks later.

---

### Step 5: Save the candidate

1. Scroll to the bottom of the form.
2. Click the **Create Candidate** button.

*Why this matters:* This saves everything you entered and creates the candidate record.

---

### What you should see

After saving:
- A green success message appears briefly
- You're taken to the candidate's profile page
- The candidate's name appears at the top
- Basic info shows on the right side (department, type, dates)

[Screenshot: Candidate profile page after creation]

> **If something looks wrong:** Check that all required fields were filled in. If you see a red error message, read it—it tells you what's missing.

## Part 2: Create a Task in the Task Library

**What is the Task Library?**  
The Task Library is a saved list of reusable tasks. Think of it like a recipe book—you create a task once, then use it in many different checklists (templates). This saves time and keeps things consistent.

---

### Step 1: Open the Task Library

1. Look at the left side of your screen.
2. Click **Task Library** in the menu.

*Why this matters:* This is where you create and manage your reusable tasks.

[Screenshot: Left sidebar with Task Library highlighted]

---

### Step 2: Click "New Task Definition"

1. Look in the top-right corner.
2. Click the button that says **+ New Task Definition**.

*Why this matters:* This opens the form where you describe what needs to happen.

[Screenshot: Task Library page with New button circled]

---

### Step 3: Enter a task name

1. In the **Name** field, type a short, clear description of what needs to be done.

**Example:** `Complete Background Check Form`

*Why this matters:* This name appears everywhere—make it easy to understand at a glance.

> **Tip:** Start with an action word like "Complete," "Submit," "Schedule," or "Review."

---

### Step 4: Add a description (optional but helpful)

1. In the **Description** field, add more details.

**Example:**  
`New hire must complete and sign the background check authorization form. Contact hr@company.com with questions.`

*Why this matters:* Descriptions help the person doing the task know exactly what's expected.

---

### Step 5: Save the task

1. Click the **Create** button.

*Why this matters:* Your task is now saved in the library and ready to use in templates.

---

### What you should see

After saving:
- A success message appears
- Your new task shows up in the Task Library list

[Screenshot: Task Library with new task visible]

---

### Understanding Task Fields

When you add a task to a template (covered in Part 3), you'll see more fields. Here's what they mean:

| Field | Plain English Explanation |
|-------|---------------------------|
| **Task name** | What needs to happen. Keep it short and clear. |
| **Who owns it** | The person or role responsible. Could be "HR Staff," a specific person, or even "Candidate" (the new hire themselves). |
| **Due date rule** | When the task is due, based on a key date. Example: "3 days after Start Date." |
| **Category** | What type of task this is: HR, IT, Facilities, etc. Helps with filtering. |
| **Candidate-visible** | If checked, the candidate can see this task in their portal. Turn off for internal-only tasks. |
| **Notes/links** | Extra information like instructions, links to forms, or contact info. |

---

### Example: Create a Real Task

Let's create a task you might actually use:

| Field | What to Enter |
|-------|---------------|
| Name | `Submit Direct Deposit Form` |
| Description | `Fill out the direct deposit form for payroll. Find the form at hr.company.com/forms. Return to HR by your first week.` |

This task will now be available to add to any template.

---

### How to Edit, Duplicate, or Deactivate a Task

Sometimes you need to change a task after you create it:

**To edit a task:**
1. Find the task in the Task Library list.
2. Click the pencil icon (or "Edit" button) on that row.
3. Change what you need.
4. Click **Save**.

**To deactivate a task:**
1. Click the archive or deactivate button on the task row.
2. Confirm when asked.

*What this means:* The task won't show up when building new templates, but existing uses aren't affected.

**To see deactivated tasks:**
1. Look for a "Show Archived" toggle.
2. Turn it on to see hidden tasks.

> **Note:** There's no duplicate button in the Task Library—just create a new task with a similar name if needed.

## Part 3: Create a Template

**What is a template?**  
A template is a reusable checklist. Instead of adding the same 20 tasks for every new hire, you create a template once and apply it to each candidate. The system then generates all the tasks automatically.

---

### Step 1: Open the Templates page

1. Look at the left side of your screen.
2. Click **Templates** in the menu.

*Why this matters:* This is where you create and manage your reusable checklists.

[Screenshot: Left sidebar with Templates highlighted]

---

### Step 2: Click "New Template"

1. Look in the top-right corner.
2. Click **+ New Template**.

*Why this matters:* This starts the process of building a new checklist.

[Screenshot: Templates page with New Template button circled]

---

### Step 3: Name your template

1. In the **Name** field, type a clear name.

**Example:** `Staff Onboarding Checklist`

*Why this matters:* You'll pick this template by name when creating candidates, so make it recognizable.

---

### Step 4: Choose a Candidate Type

1. In the **Candidate Type** dropdown, select who this template is for.

**Example:** Select "Staff"

*Why this matters:* Only candidates of this type will see this template as an option. This prevents mixing up faculty and staff checklists.

---

### Step 5: Add a description (optional)

1. In the **Description** field, explain what this template is for.

**Example:** `Standard onboarding checklist for new staff members`

---

### Step 6: Save the template

1. Click **Create**.

*Why this matters:* This creates the template shell. Next, you'll add stages and tasks.

---

### What you should see

After saving:
- You're taken to the template editor page
- The template shows as "Draft" or "Inactive"
- There are empty sections for Stages and Tasks

[Screenshot: Empty template editor page]

---

### Step 7: Add a stage

Stages are groups of related tasks. For example, "Pre-Start Paperwork" or "First Week."

1. Find the **Add Stage** section.
2. Select a stage from the dropdown (like "Documentation" or "Onboarding").
3. Choose a **Phase**:
   - **Pre-hire** = Tasks before their start date
   - **Onboarding** = Tasks on or after their start date
4. Click **Add Stage**.

*Why this matters:* Stages organize your tasks into logical groups, making the checklist easier to follow.

[Screenshot: Add Stage dropdown and button]

---

### Step 8: Add tasks from the library

Now, add the tasks you created earlier:

1. Click **+ Add Task** (or look for "Add Task to Stage").
2. A form appears with these fields:

| Field | What to Enter |
|-------|---------------|
| Task Definition | Pick a task from your Task Library |
| Stage | Which stage this task belongs to |
| Due Date Rule | When it's due (see next step) |
| Owner | Who's responsible |
| Priority | How important: Low, Medium, High |
| Required | Must it be done to move forward? Yes/No |

3. Fill in each field.
4. Click **Save**.

*Why this matters:* You're building your checklist by adding one task at a time.

[Screenshot: Add Task form with fields labeled]

---

### Step 9: Set due dates using anchor dates

**What's an anchor date?**  
An anchor date is a key date that other due dates are calculated from. The most common anchors are:

- **Offer Letter Date** – When they accepted the offer
- **Start Date** – Their first day of work

**Examples of due date rules:**

| Rule | What It Means |
|------|---------------|
| On Start Date | Due the day they start |
| 7 days before Start Date | Due one week before they start |
| 3 days after Offer Accepted | Due 3 days after they sign |
| Fixed Date | Due on a specific calendar date |

When adding a task, pick a rule that makes sense:

1. Select a **Due Date Rule** (like "Days Before Start Date").
2. If needed, enter a number (like "7" for 7 days).

*Why this matters:* The system automatically calculates exact due dates based on each candidate's dates.

> **Tip:** Use "Before Start Date" for paperwork that must be done before Day 1. Use "After Start Date" for things that happen during their first week.

---

### Step 10: Arrange tasks in order

Tasks within a stage can be reordered:

1. Look for a drag handle (usually looks like ⋮⋮ or ☰) next to each task.
2. Click and drag to move tasks up or down.
3. Release to drop in the new position.

*Why this matters:* Order can show priority or logical sequence.

---

### Step 11: Activate (publish) the template

A template starts as "Draft," which means it can't be used yet. To make it available:

1. Look for an **Activate** button or status toggle.
2. Click to activate.
3. If you see an error, fix what's missing (see below).

*Why this matters:* Only active templates appear when creating new candidates.

**Before you can activate, check that:**
- ✅ At least one stage exists
- ✅ Every stage has at least one task
- ✅ Every task has a due date rule set
- ✅ Every task has an owner assigned

[Screenshot: Template with Activate button highlighted]

---

### What you should see

After activating:
- Status changes to "Active"
- The template appears in the dropdown when creating candidates

> **If something looks wrong:** Read the error message. It tells you what's missing. Usually it's an empty stage or a task without a due date rule.

## Part 4: Working With Candidates (Everyday Workflow)

Now that you know how to create candidates, tasks, and templates, here's how you'll use OnBoardPro day-to-day.

---

### Assign a template to a candidate

You have two options:

**Option A: When creating a new candidate**
1. Follow the steps in Part 1.
2. In the **Template** dropdown, select the template you want.
3. Save the candidate.

**Option B: After the candidate already exists**
1. Open the candidate's profile.
2. Look for a section about templates or an "Apply Template" button.
3. Select a template and confirm.

*Why this matters:* The template tells OnBoardPro which tasks to create for this person.

---

### Generate the task list

Tasks are created automatically when you set the **Offer Letter Accepted** date. Here's what happens:

1. You enter (or update) the Offer Accepted date on the candidate.
2. OnBoardPro reads the template.
3. It calculates each task's due date based on the candidate's dates.
4. All tasks appear on the candidate's profile.

[Screenshot: Candidate profile with task list visible]

> **Note:** If you skip the Offer Accepted date, no tasks appear yet. Add the date when you're ready.

---

### Update task statuses

As work gets done, update each task's status. Here's what each status means:

| Status | What It Means | When to Use |
|--------|---------------|-------------|
| **Not started** (To Do) | Work hasn't begun | Default for new tasks |
| **Working on it** (In Progress) | Someone is actively doing this | When you start |
| **Blocked** | Can't proceed—waiting on something | When stuck |
| **Done** | Finished! | When complete |
| **Canceled** | No longer needed | When task is removed |

**To change a status:**
1. Go to the candidate's profile.
2. Find the task.
3. Click the status dropdown.
4. Select the new status.

*Why this matters:* Updated statuses show progress and help the team know what's left.

[Screenshot: Task with status dropdown open]

> **Tip:** When all required tasks in a stage are "Done," the candidate automatically moves to the next stage!

---

### Handle common changes

Things change. Here's how to handle the most common situations:

---

#### When the start date changes

1. Open the candidate's profile.
2. Click **Edit** (usually a pencil icon or button).
3. Change the **Anticipated Start Date** field.
4. Save.

**What happens:** All due dates automatically recalculate based on the new date.

[Screenshot: Editing candidate dates]

---

#### When you need to assign a task to a different person

1. Find the task on the candidate's profile.
2. Click the current owner's name (or the assignee dropdown).
3. Select a different person.
4. The change saves automatically (or click Save).

**What happens:** The new person gets notified and the task appears on their list.

---

#### When you need to add a new task

1. On the candidate's profile, look for **+ Add Task**.
2. You can:
   - Pick an existing task from the library, OR
   - Create a custom one-time task
3. Set the stage, due date, and owner.
4. Save.

**What happens:** The new task appears on the candidate's task list.

---

#### When you need to remove a task

You can't delete a task, but you can cancel it:

1. Find the task.
2. Change the status to **Canceled**.
3. Enter a brief reason (required).
4. Confirm.

**What happens:** The task stays for record-keeping but no longer blocks progress.

---

#### When you need to reopen a finished task

Sometimes a "Done" task needs more work:

1. Find the completed task.
2. Click the status.
3. Change it back to **Working on it** or **Not started**.

**What happens:** The task is active again and shows as incomplete.

---

## 10-Minute Practice Walkthrough

Let's put it all together! Follow these steps to practice the complete workflow.

---

### Minutes 1–2: Create a task in the library

1. Click **Task Library** in the left menu.
2. Click **+ New Task Definition**.
3. Enter:
   - **Name:** `Practice Task – Submit Paperwork`
   - **Description:** `This is a practice task for learning OnBoardPro.`
4. Click **Create**.

**Checkpoint:** Your task appears in the list. ✓

---

### Minutes 3–5: Create a template

1. Click **Templates** in the left menu.
2. Click **+ New Template**.
3. Enter:
   - **Name:** `Practice Template`
   - **Candidate Type:** (Pick any available type)
4. Click **Create**.
5. Add a stage:
   - Select any stage from the dropdown
   - Choose **Pre-hire** as the phase
   - Click **Add Stage**
6. Add your task:
   - Click **+ Add Task**
   - **Task Definition:** `Practice Task – Submit Paperwork`
   - **Stage:** (Your stage)
   - **Due Date Rule:** `5 Days After Offer Accepted`
   - **Priority:** Medium
   - **Required:** Yes
   - Click **Save**
7. Click **Activate**.

**Checkpoint:** Template status shows "Active." ✓

---

### Minutes 6–8: Create a candidate and apply the template

1. Click **Candidates** in the left menu.
2. Click **+ New Candidate**.
3. Enter:
   - **Salutation:** Ms.
   - **First Name:** Practice
   - **Last Name:** User
   - **Email:** practice.user@example.com
   - **Candidate Type:** (Same type as your template)
   - **Department:** (Pick any)
   - **Letter of Intent Date:** Today's date
   - **Offer Letter Accepted:** Today's date
   - **Anticipated Start Date:** 2 weeks from today
   - **Template:** `Practice Template`
4. Click **Create Candidate**.

**Checkpoint:** You're on the candidate's profile and see "Practice Task" in the task list. ✓

---

### Minutes 9–10: Complete a task

1. Find "Practice Task – Submit Paperwork" in the task list.
2. Click the status dropdown.
3. Change it from **To Do** → **In Progress**.
4. Click the status again.
5. Change it from **In Progress** → **Done**.

**Checkpoint:** The task shows as Done with a green indicator. ✓

---

🎉 **Congratulations!** You've completed the full workflow!

## Common Issues & Fixes

Here are problems you might run into and how to solve them:

| Issue | Why It Happens | How to Fix |
|-------|----------------|------------|
| **"Template cannot be activated"** | A stage has no tasks | Add at least one task to every stage |
| **Can't find my template when creating a candidate** | Template is inactive OR wrong candidate type | Activate the template and check the type matches |
| **Task shows "Pending Date"** | Missing date on candidate (Offer Accepted or Start Date) | Edit the candidate and add the missing date |
| **Due dates didn't update when I changed Start Date** | Rare cache issue | Refresh the page; dates should update |
| **Candidate is stuck at a stage** | Required tasks aren't done | Mark all required tasks as Done |
| **Can't change the template after applying it** | Templates lock after application | Add/remove individual tasks instead |
| **Task doesn't appear for the assignee** | Wrong person selected | Edit the task and change the owner |
| **I accidentally completed a task** | Clicked Done too soon | Change the status back to In Progress or To Do |
| **I don't see the Task Library in the menu** | Permissions issue | Ask your admin to give you Task Library access |
| **Template dropdown is empty** | No active templates for this candidate type | Create and activate a template for that type |
| **I can't delete a task** | Tasks are kept for records | Cancel the task instead of deleting |
| **Error when saving candidate: "Department required"** | Field left blank | Select a department from the dropdown |
