Feature: Add Faculty Rank to New Candidate dialog

Goal
- Extend the New Candidate dialog so users can assign a Faculty Rank to candidates during creation.
- Faculty Rank values come from the faculty_ranks table in the database.
- The field is optional for non-faculty candidate types, required for faculty types.

Database
- Ensure the candidates table has a faculty_rank_id column:
  DO $$
  BEGIN
    IF NOT EXISTS (
      SELECT 1 FROM information_schema.columns
      WHERE table_name = 'candidates' AND column_name = 'faculty_rank_id'
    ) THEN
      ALTER TABLE candidates
      ADD COLUMN faculty_rank_id uuid REFERENCES faculty_ranks(id);
    END IF;
  END$$;

- faculty_ranks table exists with seeded values: Assistant, Associate, Professor, Other.

API
1) GET /api/faculty-ranks
   - Return all active faculty ranks (id, name).
   - Protect: only system_admin, hr_staff, department_admin can read.
   - Example query:
     SELECT id, name FROM faculty_ranks WHERE archived = false ORDER BY sort_order, name;

2) Include faculty_rank_id in POST /api/candidates
   - Optional field, nullable unless candidate_type = 'Faculty' or 'Faculty Clinical'.
   - Validation: if candidate_type in ('Faculty','Faculty Clinical') and faculty_rank_id is NULL, reject with 400.

Frontend (New Candidate dialog)
- Add Faculty Rank select field.
- Label: “Faculty Rank”
- Required only when Candidate Type is Faculty or Faculty Clinical. Otherwise optional and hidden or disabled.
- Options fetched with TanStack Query:
  useQuery({
    queryKey: ['faculty_ranks'],
    queryFn: () => fetch('/api/faculty-ranks').then(r=>r.json()),
    staleTime: 60_000
  })

- Behavior:
  - When Candidate Type is Faculty or Faculty Clinical → Faculty Rank select is enabled and required.
  - For Staff, Clinical, or Other → hide the field or disable it.
  - On submit, include faculty_rank_id in body if selected.

Form example payload:
{
  salutation: "Dr",
  first_name: "Alice",
  last_name: "Smith",
  email: "alice@example.edu",
  candidate_type_id: "...faculty...",
  department_id: "...",
  division_id: "...",
  manager_id: "...",
  faculty_rank_id: "...assistant...",
  start_date: "2025-09-15",
  template_id: "...",
  notes: "New faculty hire"
}

Acceptance
- Faculty Rank dropdown shows seeded ranks from DB.
- Field is required when Candidate Type is Faculty or Faculty Clinical.
- Field is hidden/disabled for non-faculty types.
- Submitting stores faculty_rank_id correctly in candidates table.
- API rejects missing faculty_rank_id if type is Faculty/Faculty Clinical.
