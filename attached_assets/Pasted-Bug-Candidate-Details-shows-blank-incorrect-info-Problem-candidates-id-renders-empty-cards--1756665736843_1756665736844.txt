Bug: Candidate Details shows blank/incorrect info

Problem
- /candidates/[id] renders empty cards (“Not set”) and no tasks.
- Likely causes: missing API, wrong route param usage, queries not joined, or filters hiding data.

Goal
- Load candidate info by id and list that candidate’s tasks, grouped by stage.
- Show skeletons while loading, error state if fetch fails.
- Tasks exist only on the candidate profile.
- Stage Timeline tab should render candidate_stage_history in chronological order.

Backend API (create or fix)

1) GET /api/candidates/:id
   Returns a single candidate with joined display fields.
   [same query as before; see previous prompt]

2) GET /api/candidates/:id/tasks
   Returns all candidate_tasks for that candidate, joined to stage and definition.
   [same query as before]

3) GET /api/candidates/:id/stage-history
   Returns candidate_stage_history ordered by changed_at ASC.
   SQL shape:
   SELECT
     sh.id,
     sh.stage_id,
     hs.name AS stage_name,
     sh.changed_at,
     sh.changed_by,
     u.name AS changed_by_name
   FROM candidate_stage_history sh
   LEFT JOIN hiring_stages hs ON hs.id = sh.stage_id
   LEFT JOIN users u ON u.id = sh.changed_by
   WHERE sh.candidate_id = $1
   ORDER BY sh.changed_at ASC;

   Response JSON example:
   {
     "history": [
       { "id":"…", "stage":{"id":"…","name":"LOI"}, "changed_at":"2025-08-01T10:00:00Z", "changed_by":{"id":"…","name":"HR Staff"} },
       { "id":"…", "stage":{"id":"…","name":"Offer"}, "changed_at":"2025-08-15T09:00:00Z", "changed_by":{"id":"…","name":"System Admin"} }
     ]
   }
