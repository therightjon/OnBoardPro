Table: templates
- id uuid PK default gen_random_uuid()
- name text NOT NULL  -- unique case-insensitive
- candidate_type_id uuid NOT NULL REFERENCES candidate_types(id)
- description text NULL
- is_active boolean NOT NULL DEFAULT true
- archived boolean NOT NULL DEFAULT false
- created_by uuid NULL REFERENCES users(id)
- created_at timestamp NOT NULL DEFAULT now()
- updated_at timestamp NOT NULL DEFAULT now()

Indexes and constraints (templates)
- UNIQUE INDEX ON lower(name)
- INDEX ON candidate_type_id
- Trigger to set updated_at on UPDATE

Table: template_tasks
- id uuid PK default gen_random_uuid()
- template_id uuid NOT NULL REFERENCES templates(id) ON DELETE CASCADE
- task_def_id uuid NOT NULL REFERENCES task_definitions(id)
- stage_id uuid NOT NULL REFERENCES hiring_stages(id)
- due_rule_type due_rule_type NOT NULL
  -- enum values: 'days_before_start','days_after_start','days_before_stage','days_after_stage','fixed_date'
- due_rule_value integer NULL        -- required for relative rules, NULL for fixed_date
- fixed_date date NULL               -- used only when due_rule_type = 'fixed_date'
- default_assignee_id uuid NULL REFERENCES users(id)
- default_priority_id uuid NULL REFERENCES task_priorities(id)
- default_category_id uuid NULL REFERENCES task_categories(id)
- archived boolean NOT NULL DEFAULT false
- created_by uuid NULL REFERENCES users(id)
- created_at timestamp NOT NULL DEFAULT now()
- updated_at timestamp NOT NULL DEFAULT now()

Indexes and constraints (template_tasks)
- INDEX ON template_id
- UNIQUE(template_id, task_def_id, stage_id) WHERE archived = false  -- prevent accidental duplicates per stage
- Check constraints:
  - If due_rule_type = 'fixed_date' then fixed_date IS NOT NULL and due_rule_value IS NULL
  - If due_rule_type <> 'fixed_date' then due_rule_value IS NOT NULL and fixed_date IS NULL
- Trigger to set updated_at on UPDATE

SQL migration (idempotent)
- Ensure extension and enum exist:
  - CREATE EXTENSION IF NOT EXISTS pgcrypto;
  - DO $$ BEGIN
      IF NOT EXISTS (SELECT 1 FROM pg_type WHERE typname = 'due_rule_type') THEN
        CREATE TYPE due_rule_type AS ENUM ('days_before_start','days_after_start','days_before_stage','days_after_stage','fixed_date');
      END IF;
    END $$;

- Create templates table:
  - CREATE TABLE IF NOT EXISTS templates (
      id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
      name text NOT NULL,
      candidate_type_id uuid NOT NULL REFERENCES candidate_types(id),
      description text NULL,
      is_active boolean NOT NULL DEFAULT true,
      archived boolean NOT NULL DEFAULT false,
      created_by uuid NULL REFERENCES users(id),
      created_at timestamp NOT NULL DEFAULT now(),
      updated_at timestamp NOT NULL DEFAULT now()
    );
  - CREATE UNIQUE INDEX IF NOT EXISTS templates_name_unique ON templates((lower(name)));
  - CREATE INDEX IF NOT EXISTS idx_templates_candidate_type ON templates(candidate_type_id);

- Create template_tasks table:
  - CREATE TABLE IF NOT EXISTS template_tasks (
      id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
      template_id uuid NOT NULL REFERENCES templates(id) ON DELETE CASCADE,
      task_def_id uuid NOT NULL REFERENCES task_definitions(id),
      stage_id uuid NOT NULL REFERENCES hiring_stages(id),
      due_rule_type due_rule_type NOT NULL,
      due_rule_value integer NULL,
      fixed_date date NULL,
      default_assignee_id uuid NULL REFERENCES users(id),
      default_priority_id uuid NULL REFERENCES task_priorities(id),
      default_category_id uuid NULL REFERENCES task_categories(id),
      archived boolean NOT NULL DEFAULT false,
      created_by uuid NULL REFERENCES users(id),
      created_at timestamp NOT NULL DEFAULT now(),
      updated_at timestamp NOT NULL DEFAULT now()
    );
  - CREATE INDEX IF NOT EXISTS idx_template_tasks_template ON template_tasks(template_id);

- Checks and partial unique:
  - DO $$
    BEGIN
      IF NOT EXISTS (
        SELECT 1 FROM pg_constraint WHERE conname = 'chk_template_tasks_due_rules'
      ) THEN
        ALTER TABLE template_tasks
        ADD CONSTRAINT chk_template_tasks_due_rules
        CHECK (
          (due_rule_type = 'fixed_date'    AND fixed_date IS NOT NULL AND due_rule_value IS NULL)
          OR
          (due_rule_type <> 'fixed_date'   AND due_rule_value IS NOT NULL AND fixed_date IS NULL)
        );
      END IF;
    END $$;

  - DO $$
    BEGIN
      IF NOT EXISTS (
        SELECT 1 FROM pg_indexes WHERE indexname = 'uniq_template_tasks_per_stage'
      ) THEN
        CREATE UNIQUE INDEX uniq_template_tasks_per_stage
        ON template_tasks(template_id, task_def_id, stage_id)
        WHERE archived = false;
      END IF;
    END $$;

- updated_at trigger helper:
  - CREATE OR REPLACE FUNCTION set_updated_at() RETURNS trigger AS $$
      BEGIN NEW.updated_at = now(); RETURN NEW; END;
    $$ LANGUAGE plpgsql;

  - DROP TRIGGER IF EXISTS trg_templates_updated_at ON templates;
    CREATE TRIGGER trg_templates_updated_at
    BEFORE UPDATE ON templates
    FOR EACH ROW EXECUTE FUNCTION set_updated_at();

  - DROP TRIGGER IF EXISTS trg_template_tasks_updated_at ON template_tasks;
    CREATE TRIGGER trg_template_tasks_updated_at
    BEFORE UPDATE ON template_tasks
    FOR EACH ROW EXECUTE FUNCTION set_updated_at();

API: POST /api/templates (create)
- Body:
  - name, candidate_type_id, description?, is_active? (default true), clone_from_template_id? (optional)
- Behavior:
  - Insert into templates.
  - If clone_from_template_id is present:
    - Copy all non-archived rows from template_tasks where template_id = clone_from_template_id into the new template_id.
    - Preserve task_def_id, stage_id, due_rule_type, due_rule_value, fixed_date, default_* fields.
  - Return new template id.

Acceptance
- Creating a template with required fields succeeds and shows on /templates.
- Name is unique case-insensitive.
- Cloning produces a new template with copied template_tasks.
- Template Tasks enforce due rule checks.
- Only system_admin and hr_staff can see the “New Template” button and create templates.
