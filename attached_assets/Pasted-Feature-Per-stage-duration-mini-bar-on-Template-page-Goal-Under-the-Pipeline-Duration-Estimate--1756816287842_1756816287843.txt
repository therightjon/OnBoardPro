Feature: Per-stage duration mini bar on Template page

Goal
- Under the “Pipeline Duration Estimate” card, show a compact bar list of stages with their latest offset (in days) from the estimate API.
- Bars scale relative to the max stage offset so admins can see the “long pole.”

API (already returns this)
- GET /api/templates/:id/estimate?start=YYYY-MM-DD&businessDays=true|false
  includes:
  {
    perStage: [
      { stageId, stageName, latestOffsetDays, latestDate? }
    ],
    totalCalendarDays
  }

Frontend

1) Add a component: src/components/template/PerStageMiniBar.tsx

'use client';
import * as React from 'react';

type Stage = { stageId: string; stageName: string; latestOffsetDays: number; latestDate?: string };

export function PerStageMiniBar({ stages }: { stages: Stage[] }) {
  if (!stages?.length) {
    return <p className="text-sm text-muted-foreground">No stage timing available.</p>;
  }

  const max = Math.max(...stages.map(s => s.latestOffsetDays ?? 0), 1);

  return (
    <div className="space-y-2" role="list" aria-label="Stage duration overview">
      {stages
        .slice()
        .sort((a, b) => a.latestOffsetDays - b.latestOffsetDays)
        .map((s) => {
          const pct = Math.max(0, Math.min(100, Math.round((s.latestOffsetDays / max) * 100)));
          return (
            <div key={s.stageId} role="listitem" className="flex items-center gap-3">
              <div className="w-40 shrink-0 text-sm text-foreground truncate" title={s.stageName}>
                {s.stageName}
              </div>
              <div className="relative h-2 w-full rounded bg-muted">
                <div
                  className="absolute left-0 top-0 h-2 rounded bg-primary"
                  style={{ width: `${pct}%` }}
                  aria-hidden="true"
                />
              </div>
              <div className="w-24 shrink-0 text-right text-xs text-muted-foreground">
                {s.latestOffsetDays ?? 0}d{ s.latestDate ? ` · ${new Date(s.latestDate).toLocaleDateString()}` : '' }
              </div>
            </div>
          );
        })}
    </div>
  );
}

2) Use it on the Template page (under the Estimate card)

- Wherever you render the estimate, you already fetch:
  const { data: est } = useQuery(['templateEstimate', templateId, start, businessDays], ...)

- Inside the estimate card, after the headline, render:

import { PerStageMiniBar } from '@/components/template/PerStageMiniBar';

{est?.perStage?.length ? (
  <div className="mt-4">
    <h4 className="mb-2 text-sm font-medium text-foreground">Per-stage latest offsets</h4>
    <PerStageMiniBar stages={est.perStage} />
  </div>
) : null}

3) UX details
- Bars sort ascending by offset; the longest bar is 100%.
- Right-hand label shows “Xd · <date>” when a start date is provided and the API includes latestDate.
- Keep the whole section in the Estimate card so it travels with the Start Date.

4) Empty/edge cases
- If all latestOffsetDays are 0, bars render at minimum width (handled by max=1 safeguard).
- If API returns [], hide the section.
- If some stages are non-estimable, they will be absent from perStage; make sure you still show the top-level “Excluded N tasks …” note from the estimate.

Acceptance
- With the start date set, the mini bar shows each stage and its latest due offset; the longest stage reaches the card width.
- No extra libraries added; renders fast and works on mobile widths.
